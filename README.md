## Engineering Principles

- **Correctness over appearances.** A successful request isn't necessarily a successful outcome.
- **Measure before optimizing.** Performance claims need evidence.
- **Security by design.** Protect data, validate boundaries, and plan for failure.
- **Make failures observable.** Systems should explain what's happening when things go wrong.
- **Ship useful software.** Perfect architecture is a wonderful way to never finish anything.
